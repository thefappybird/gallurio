# Gallurio Portfolio Maker YouTube demo script

An editable filming script for an 8–11 minute dedicated Portfolio Maker walkthrough. It presents Gallurio’s public portfolio as a configurable creative storefront for a studio’s galleries, projects, and skills—connected to inquiries, not reduced to a booking funnel.

## Before recording

- Start with a dedicated demo workspace and fictional creative work. Prepare at least two photo collections, meaningful alt text, a logo, and a published portfolio you can open publicly.
- Decide the exact template, colors, fonts, and blocks before recording. Create a named backup draft so you can demonstrate versions safely.
- Open the public Portfolio Maker demo only if you want to show the hands-on sandbox. It is deliberately not a real publishing path; use an authenticated demo workspace to show saving, preview, and publishing.
- Do not expose Cloudflare, browser storage, private URLs, real client submissions, or unpublished work you do not have permission to show.

## Story used throughout

`[Studio name]` wants a public home for its recent work, gallery collections, and brand—then wants visitors to have a direct way to inquire. The finished site has exactly three public destinations: Home, Gallery, and Contact.

## Optional sandbox segment

If you want a short public teaser before the authenticated workflow, record `/portfolio-maker-demo` for 20–30 seconds:

1. Choose **Show me around** for the guided tour, or **I’ll explore myself** to reach the editor entry screen.
2. Start from scratch and make one harmless visual change.
3. Do **not** portray its Publish button as a real publish. The public demo intentionally keeps work out of the database and gates publishing behind sign-up.
4. Cut to the authenticated demo workspace for the real drafts, preview, and publish section.

## Edit notes

- Open with the finished public work. It gives viewers a reason to care about the controls that follow.
- Record uploads and long drag actions as separate takes, then cut them down. Keep one real drag-and-drop moment so the editor feels tangible.
- Use a consistent `[Studio name]`, color palette, and collection names throughout. Avoid empty canvases and generic placeholder copy in the final cut.
- Avoid claims that a portfolio guarantees search rankings, leads, or bookings. It can help a business present work and create a clear inquiry path; no platform can guarantee indexing or rankings.
- Add chapter cards after editing: `The finished portfolio`, `Editor overview`, `Blocks`, `Photos and Gallery`, `Navigation`, `Contact form`, `Theme`, `Preview`, `Drafts and Publish`.
