## Recommended copy changes from the current page

1. Replace “The booking-ready portfolio, run like a ledger.” with “Show your work. Capture bookings. Run your business.” The current line is memorable, but the replacement explains the product faster.
2. Keep “What is Gallurio?” but make the answer more outcome-oriented.
3. Add “invoices” and “team roles” to the homepage feature explanation because they are important Pro features.
4. Repeat “one month free, no card required” beside the main CTA and in the pricing teaser.
5. Keep “Coming soon” visible while paid subscriptions are unavailable.
6. Avoid implying that Gallurio provides photography, event planning, or other creative services. Present Gallurio as software used by those businesses.
7. Avoid claims about guaranteed bookings, increased revenue, or client conversion unless you have evidence to support them.
